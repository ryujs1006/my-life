# MY LIFE PWA — 초기 실행 패키지

이 패키지는 Mac 없이 시작할 수 있는 반응형 설치형 웹앱(PWA) 초기 버전입니다.

## 현재 포함된 기능
- 오늘 할 일: 추가, 완료 체크, 삭제
- 2주 일정: 날짜별 일정 추가 및 표시 (오늘 할 일과 별도)
- 루틴: 추가, 완료 체크, 삭제
- 연간 목표: 카테고리 추가, 세부 목표 추가 및 체크
- 버킷리스트: 목표일, 설명, 달성 처리
- 모바일/태블릿/PC 반응형 레이아웃
- 브라우저 로컬 저장(localStorage)
- PWA manifest 및 service worker 기본 캐시

## 중요한 제한
- 현재 데이터는 사용 중인 브라우저/기기에만 저장됩니다. 다른 기기와 가족 간 공유, iCloud 동기화, 사진 업로드, 실제 예약 알림/푸시, 홈 화면 위젯은 아직 연결되지 않았습니다.
- PWA 홈 화면 설치는 App Store 배포와 다릅니다.
- iCloud 직접 동기화 대신 가족 공유까지 고려해 Supabase 같은 클라우드 DB를 붙이는 구성을 권장합니다.
- 실서비스 공개 전 로그인, 사용자별 권한(RLS), 백업/복구, 개인정보 처리방침, 오류 처리 및 보안 검토가 필요합니다.

## 무료 배포 예시: GitHub Pages
1. GitHub 계정을 만들고 새 저장소를 생성합니다. 예: `my-life`.
2. 압축을 풀어 파일 전체를 저장소 루트에 업로드합니다.
3. 저장소 Settings → Pages → Build and deployment에서 배포 방식을 설정합니다.
4. 정적 파일 사이트이므로 저장소 루트에서 배포할 수 있습니다. HTTPS를 활성화합니다.
5. 생성된 `https://계정명.github.io/my-life/` 주소를 Safari에서 엽니다.

GitHub Pages 무료 제공 범위는 공개 저장소 기준입니다. 공개 저장소에 개인 정보나 실제 가족 일정을 넣지 마세요. 클라우드 로그인/DB를 연결하기 전까지는 테스트 데이터만 사용하세요.

## iPhone 홈 화면 설치
1. Safari에서 배포된 HTTPS 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. '홈 화면에 추가'를 선택합니다.
4. '웹 앱으로 열기' 옵션이 표시되면 켭니다.
5. 추가를 누릅니다.

## 다음 개발 단계
1. Supabase Auth로 개인/가족 계정 로그인 구현
2. 데이터 테이블과 Row Level Security 정책 구축
3. 이미지 저장소와 사진 첨부
4. 사용자별 알림 예약 및 Web Push
5. 루틴/일정 반복 규칙과 시간대 처리
6. 위젯 대체용 홈 대시보드 및 iOS 위젯 가능성 재검토

## 로컬 테스트
이 폴더를 HTTPS 정적 호스팅에 배포하는 것이 가장 간단합니다. 또는 개발용 서버에서 실행할 수 있습니다. 단순 파일 더블클릭(file://)은 Service Worker/PWA 테스트에 적합하지 않습니다.
